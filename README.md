# Brisk Internet

A responsive React website for Brisk Internet, built with Vite and a single site stylesheet.

## Stack

- React 19
- Vite 7
- Local brand, service, and partner assets in `public/assets/`

## Pages

Home, About, Packages, Offers, Bill Pay, Contact, Connection Enquiry, Privacy, and Terms.

## Run

```sh
npm install
npm run dev
```

Vite starts at `http://127.0.0.1:4173/` by default and selects another available port if needed.

## Build

```sh
npm run build
npm run preview
```

Contact and connection forms prepare an email using the visitor's email application. This project has no backend and does not process payments or store form submissions.
